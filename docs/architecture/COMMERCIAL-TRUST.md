# 汪连 ArchieLink｜外网访问专家 — 商业信任与授权架构

**状态：** Accepted v1  
**日期：** 2026-11-06  
**适用版本：** V0.4 前置硬约束  
**关联规格：** [SPEC.md](../product/SPEC.md) · [BUSINESS-CASE.md](../product/BUSINESS-CASE.md)

## 1. 目标

在保持故障恢复可离线执行的前提下，降低授权复制、测试后门、公钥替换、设备共享、退款后继续使用和供应链篡改风险。

本架构不承诺本地 Go 二进制“不可破解”。安全目标按优先级排列：

1. 单次错误配置不能让用户整机断网。
2. 正式构建不能包含测试授权或可替换信任根。
3. 商业权益由服务端签发、撤销和限额；网络数据面不依赖服务端。
4. 破解成本高于正版购买/迁移成本，但不伪装成绝对防护。

## 2. 商业资产分层

| 资产层 | 内容 | 存放位置 | 是否公开 | 商业价值 |
|---|---|---|---|---|
| 免费获客层 | `detect`、`plan`、`doctor`、风险解释、基础安装知识、JSON schema | 本地 Skill + 公开文档 | 是 | 建立信任、筛选付费需求 |
| 本地安全核心 | 共存 Gate、快照、隔离握手、受保护端点、路由/DNS 例外、健康检查、确定性回滚、平台兼容矩阵 | 签名本地二进制 | 否，但可被逆向 | 核心交付责任，不可依赖云端执行 |
| 云端控制面 | 订单校验、设备注册、短期租约、撤销、设备上限、退款/拒付、价格与功能分层、兼容策略发布、更新通道 | ArchieLink 后端 | 否 | 真正可持续的授权与运营壁垒 |
| 可选云端增值 | 多设备面板、远程只读体检、电视/鸿蒙配对、企业策略、优先支持 | ArchieLink 后端/伴侣服务 | 否 | 订阅收入的合理来源 |
| 绝不入云 | 用户网络流量、DNS 查询内容、Cookie、登录凭证、支付凭据、WireGuard 私钥、用户本地服务响应正文 | 仅本机 | 否 | 隐私与可用性红线 |

### 2.1 公开的内容

- 为什么 DNS、代理、路由和本地服务会冲突。
- 免费只读诊断和错误码。
- 通用 WireGuard 安装知识。
- 不含秘密的配置模板与安全说明。

公开这些内容不会削弱核心商业价值。把它们当作付费墙会让产品看起来像提示词商品。

### 2.2 必须保留在本地的代码

- 需要 root 的 route、DNS、WireGuard、防火墙和本地服务操作。
- 启动前快照、隔离握手、健康检查与自动回滚。
- 只在用户设备上可获得的网络所有权和受保护端点信息。
- 脱敏导出、全局锁、配置危险指令拒绝和崩溃恢复。

这些代码是商业核心，但不能因为“可能被抄”就搬到云端。云端执行无法可靠修复断网设备，也会扩大隐私和可用性风险。

### 2.3 必须由服务端控制的内容

- SkillHub Pay 订单真实性、退款、拒付和撤销状态。
- 许可证、设备绑定、设备上限、租约和功能开关。
- 价格、试用、版本权益和升级/降级。
- 吊销列表、异常设备共享和刷单/退款滥用处置。
- 正式兼容矩阵、强制安全更新和发布通道。

## 3. 信任边界

### 3.1 用户输入 → root 执行器

WireGuard 配置、域名、路径和网络服务名均视为不可信输入。

强制规则：

- 拒绝 `PreUp`、`PostUp`、`PreDown`、`PostDown` 和 `SaveConfig`。
- 配置路径必须显式、可读、非符号链接；状态文件使用 `0600`。
- resolver 文件名拒绝路径穿越。
- 失败关闭，不在未知网络层上继续写操作。

### 3.2 SkillHub Pay → 控制面

- 只接受平台/商户签名且可防重放的支付通知。
- 订单、退款和撤销必须幂等。
- 不保存微信/支付宝密码、验证码、商户私钥或完整支付凭据。
- 支付确认未经服务端验证前不得签发可用租约。

### 3.3 控制面 → 本地执行器

控制面签发短期、设备绑定、功能明确的租约。租约只表达权益，不下发任意 shell、路由命令或可执行脚本。

## 4. 设备身份与租约

### 4.1 设备密钥

- 首次运行生成 P-256 设备密钥。
- 支持 Secure Enclave 的设备把私钥生成在 Secure Enclave；不可导出的私钥签名激活/续租挑战。
- 无 Secure Enclave 时存入 macOS Keychain。
- 公钥随安装 ID 注册；安装 ID 为随机标识，不读取硬件序列号。

### 4.2 租约

建议初始参数：

- 租约有效期：7 天。
- 离线宽限期：30 天。
- 到期前 48 小时尝试续租。
- 撤销在下次联网续租时生效；高风险撤销可缩短宽限期。

租约至少包含：

```json
{
  "schema_version": "2",
  "license_id": "lic_...",
  "install_id": "anon_...",
  "device_public_key": "base64...",
  "plan": "family-annual-12",
  "features": ["network_apply"],
  "not_before": "RFC3339",
  "expires_at": "RFC3339",
  "offline_grace_until": "RFC3339",
  "lease_id": "lease_...",
  "nonce": "random",
  "revocation_epoch": 12,
  "max_devices": 12,
  "max_new_devices_per_year": 12,
  "max_new_devices_per_7_days": 3,
  "device_registration_quota_remaining": 10,
  "signature": "base64..."
}
```

### 4.3 防重放与时钟

- 每次激活/续租使用设备私钥对服务端 challenge 签名。
- 租约验证服务端签名、设备公钥、安装 ID、功能、时间窗和撤销 epoch。
- 本地记录单调递增的 `last_seen_at`；每次租约检查都会推进，任何路径都不能把它写回更早时间。
- 系统时间倒退超过 24 小时会持久化 `clock_review_required` 并阻断新 `up`；只有控制面签发的新租约可以解除标记。
- 在线续租以服务端租约的 `issued_at` 校准本地时间；即使标记已解除，时钟仍明显落后时下一次检查继续阻断。
- 不因短时离线阻断 `down` / `rollback`。安全恢复永远优先。

### 4.4 SkillHub Pay 个人通道

- 个人开发者使用支付宝 AI 按量付费，单笔金额限制为 0.01–50 CNY。
- 该通道只销售 `activation-task`，默认 19.90 CNY/次；家庭年度版和永久版不得拆成伪装成单次的任务。
- 未付款时返回 HTTP 402、`Payment-Needed` 和商家 RSA2 签名账单。
- 支付后必须调用支付宝凭证验证接口，并校验 `active`、金额、商户订单号、资源 ID 和交易号唯一性。
- 资源生成后必须调用履约确认接口；确认失败时不得返回成功，同一凭证允许重试确认。
- 付款意图绑定 `install_id` 与设备公钥；激活时必须同时要求订单已支付、订阅仍激活且设备一致。
- 一次性数字激活在履约后视为已消费。是否提供主动退款必须以 SkillHub 规则、消费者权益和
  实际售后政策为准，不能由代码单方面承诺或拒绝。
- 无论产品是否提供主动退款，平台退款、拒付、撤销或人工处置事件都必须停止续租并推进
  revocation epoch。

### 4.5 家庭年度计划的 12 台设备池

年度家庭订阅以自然订阅年度计算，最多绑定 12 台不同设备，最多同时激活 12 台。

规则：

- 一台设备首次完成设备公钥注册时消耗 1 个年度名额。
- 同一设备、同一设备密钥重装或升级不重复消耗名额。
- 更换电脑、重装导致设备密钥重置或迁移到新设备，消耗新的年度名额。
- 释放旧设备可以腾出“同时激活”位置，但不会恢复已经使用的年度设备名额。
- 每个滚动 7 天最多新增 3 台设备；超过后进入冷却或人工复核。
- macOS、Windows、Linux、鸿蒙 PC、电视伴侣等正式支持平台共用同一个 12 台池。
- 虚拟机、容器和临时服务器默认不计为家庭个人设备；需要单独授权。
- 允许账号持有人为家庭成员和朋友的个人设备进行非商业配置。
- 禁止收费代装、转售、出租、公开共享账号、捆绑硬件销售和批量部署。
- 账号持有人负责设备移除和授权管理；被移除设备的租约在下次续租/撤销同步时失效，但 `down` 和 `rollback` 永远保留。

12 台上限是防转售护栏，不是技术上的身份认定。异常设备轮换、短时间跨地域激活和批量代装仍需服务端风控或人工复核。

## 5. 构建与发布安全

### 5.1 构建档位

| 档位 | 构建标签 | 测试授权 | 运行时公钥覆盖 | 用途 |
|---|---|---|---|---|
| Release | 无 | 禁止 | 禁止 | 正式分发 |
| License Test | `licensetest` | 允许 | 允许 | 实机验收 |
| Fault Injection | `faultinjection,licensetest` | 允许 | 允许 | 故障注入 |

正式构建必须：

- 信任公钥编译期固定，不接受环境变量替换。
- `licensetest`、`faultinjection` 代码不进入二进制。
- 使用 `-trimpath`、固定 Go 工具链和锁定的依赖。
- 生成 SBOM、SHA-256 清单和签名 manifest。
- macOS 使用 Developer ID 签名、Hardened Runtime 和 notarization。

Release 构建入口：

```bash
ARCHIE_LINK_KEY_ID=<key-id> \
ARCHIE_LINK_PUBLIC_KEY=<base64-ed25519-public-key> \
sh scripts/build-release.sh
```

密钥轮换窗口通过三个可选变量注入。构建默认拒绝脏工作树，固定 `go.mod`
声明的 Go 工具链，并使用 `-trimpath -buildvcs=false`；Darwin 额外移除随机
Mach-O UUID。输出客户端、Linux 控制面、`SHA256SUMS`、CycloneDX
`sbom.cdx.json` 与 `release-manifest.json`。

同源码双构建一致性检查：

```bash
sh scripts/verify-release-reproducible.sh <release-dir-a> <release-dir-b>
```

macOS 在具备 Xcode/Clang 的构建主机上同时交叉编译 amd64 与 arm64 的 cgo
产物以包含 Secure Enclave 主路径。V0.4 以双架构编译、fake 后端编排测试、
失败回退和 fail-closed 测试作为软件验收，不要求 Apple Silicon/T2 真机。
manifest 的 `darwin_secure_enclave_arch` 和每个 Darwin artifact 的
`secure_enclave_build` 必须如实标出。没有硬件证据时，产品不得对外宣称
Secure Enclave 主路径已经硬件验证。

### 5.2 可复现性

- 相同 commit、工具链和构建脚本生成相同源码输入和依赖图。
- 发布记录 commit、构建版本、Go 版本、目标平台、标签和哈希。
- 二进制内嵌 build ID、版本、协议版本和公钥指纹。
- 升级包验证签名后原子替换；失败保留可回滚旧版本。

## 6. 滥用与定价防护

### 6.1 必须防护

- 测试授权进入正式包。
- 用户替换信任公钥自签许可证。
- 许可证复制到多台设备。
- 系统时钟回拨延长过期许可证。
- 退款/拒付后继续获取新租约。
- 高频激活、批量注册、设备轮换刷额度。
- 将 12 台家庭计划用于收费代装、转售或商业批量部署。
- 将付费 Skill 包装成任意 root 命令执行器。

### 6.2 不追求防护

- 用户手工使用自己的免费 WARP 配置。
- 用户修改自己设备上的开源 WireGuard。
- 对本地二进制进行静态分析。

产品价值不是隐藏 WireGuard 命令，而是降低配置错误、保护本地服务、自动回滚、兼容维护和支持责任。

### 6.3 对外承诺纪律

- 禁止在任何 UI、对外文档或发布文案中出现未经验证的商业承诺（退款窗口、退款期限、补偿、保价等）。
- 一切对外承诺必须有官方来源佐证；无佐证时只描述已实测事实，或明确标注「未验证」。
- 案例：2026-11-26 全仓撤回「12 个月内可退」说法——该说法系无官方依据的推断（不排除幻觉）；nowPay 订单退款当前仅能支付宝商家后台手动操作，可退窗口以支付宝官方规则为准，产品与文档不作退款期限承诺。

## 7. 混合商业模式约束

| 产品层 | 收费方式 | 服务端职责 |
|---|---|---|
| 免费体检 | 免费 | 无或仅匿名下载统计 |
| 安全激活/修复 | SkillHub Pay 按次 | 校验支付、签发短期激活租约 |
| 个人永久版 | 独立订单/许可证（需平台确认） | 1 人、2 台自有设备、当前大版本、12 个月更新 |
| 家庭年度订阅 | 年度订阅，12 台设备授权池 | 多设备、电视/鸿蒙配对和家庭设备管理 |
| B2B 企业授权 | 年度席位/设备订阅，5 席起 | 发票、设备回收、企业策略、维护/SLA |
| 其他云端增值 | 年度订阅/企业合同 | 远程只读支持、企业策略和更高设备额度 |

“永久”定义为当前大版本永久使用，包含约定期限的更新与支持，不承诺无限期免费维护所有未来版本。

个人永久版不得包含家庭 12 台池或云管理能力；企业不得用个人永久版替代席位授权。

核心网络连接不得强制每次调用云 API。订阅只应购买持续产生运营成本或持续更新的能力。

## 8. 当前实现与 V0.4 门槛

当前 V0.3 已具备：

- Ed25519 签名结构、功能/安装 ID/过期/撤销校验。
- 测试授权只在 `licensetest` 构建中存在。
- 正式构建禁止运行时公钥覆盖。
- WireGuard root hook 拒绝。
- 文件权限、全局锁、脱敏导出和确定性回滚。
- P-256 设备身份、macOS Keychain 软件密钥后端和 Secure Enclave cgo 后端均已实现。
- Secure Enclave 主路径以 fake 后端编排、fail-closed 和双架构编译验收；当前没有
  Apple Silicon/T2 真机证据，不得宣称硬件验证。
- 设备绑定 lease Provider：license 文件需匹配 Keychain 设备公钥和安装 ID。

V0.4 必须具备：

- Secure Enclave/Keychain 设备密钥双架构构建；无 SE 硬件时如实回退。
- 服务端订单、设备注册、租约和撤销接口。
- 短期租约、离线宽限、设备上限和防重放。
- 家庭年度计划 12 台设备池、3 台/7 天激活限速和亲友非商业使用条款。
- 退款/拒付后停止续租。
- 正式公钥编译期固定、签名、公证和可复现构建。
- 真实支付沙箱和退款撤销验收。
